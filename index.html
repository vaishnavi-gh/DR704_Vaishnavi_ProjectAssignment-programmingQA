About the Course

This course is designed to provide students with practical knowledge of software testing, SQL, programming, and web development. Students learn the fundamentals of manual testing, database management, programming concepts, and HTML. The course also introduces automation testing tools and helps students understand how software applications are developed, tested, and maintained. Through practical exercises and real-world projects, students can improve their technical skills, problem-solving abilities, and understanding of the software development process.

Technologies Covered

  1. Manual Testing
  2. SQL
  3. Selenium
  4. Java
  5. Python
  6. Playwright
